# treadline-site

Public pages for the Treadline iOS app, served by GitHub Pages at
https://johnhann.github.io/treadline-site/

- `privacy.html` — the privacy policy the app and App Store Connect link to:
  https://johnhann.github.io/treadline-site/privacy.html

The app itself lives in the private `treadline` repo and links here rather than bundling a copy,
so a policy change only needs a commit on this branch.
